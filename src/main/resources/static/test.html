Visa RAG Service — Test Console

Manual test harness for the live backend at . No auth; applicant IDs are opaque UUIDs you manage yourself.

Applicant ID

Every applicant-scoped call below uses this ID. Generate a fresh one to start a new test applicant, or paste an existing UUID.

Upload Passport

POST /api/v1/applicants/{applicantId}/documents/passport — full pipeline: image quality gate, OCR, MRZ parsing, vision extraction, persistence. Field candidates come back UNVERIFIED and are not yet applied to the profile.

Selecting a new file replaces the current preview and re-runs the quality checks below.

Passport photo checklist

  • ✓ All 4 passport corners are visible
  • ✓ MRZ lines are fully visible and readable
  • ✓ Passport is flat and not folded
  • ✓ Camera is parallel to the passport
  • ✓ Use even lighting
  • ✓ Avoid flash/direct light glare
  • ✓ Image should be sharp and in focus
  • ✓ Do not crop any part of the passport

Position the entire passport inside the guide.
